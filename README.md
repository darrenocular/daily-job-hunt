# daily-job-hunt

## Introduction
This is an AI-enabled app that sends users a daily digest of all job openings, geographically scoped, based on a shortlist of companies they are interested in. 

A user is able to create an account and specify a communication mode for receipt of the daily digest.

## Enhancements
Below are possible enhancements for this app:
- Allow users to interact with this app via Telegram.
- Suggest companies to users based on their shortlist.
